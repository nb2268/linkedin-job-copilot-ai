LinkedIn Job Copilot AI 💼🤖

Project Overview & Architecture Specification
Developer: Nikita Banwankar | Methodology: Prompt-Driven Agentic Engineering
Platform: Google Chrome Extension (Manifest V3) & LinkedIn Web

1. Executive Summary & Problem Solved

The Challenge: Job hunting on LinkedIn involves repetitive data entry on multi-step "Easy Apply" applications, causing fatigue and slowing down qualified candidates. Existing scrapers or headless bots risk getting accounts banned or flagged with CAPTCHAs due to unnatural automation footprints.

The Solution: An intelligent in-browser copilot agent operating within the user's authentic logged-in Chrome session. It automates 80% of repetitive application fields, evaluates skill match, drafts personalized cover notes, and pauses before submission for human verification.

2. System Architecture & Tech Stack

Core Technologies:

JavaScript (ES6+) Chrome Manifest V3 Side Panel API DOM Automation Google Gemini API HTML5 / CSS3 Python
  • Manifest V3 Service Worker: Manages lifecycle events, storage persistence, and panel orchestration.
  • Content Script (content.js): Injects into LinkedIn tabs, parses active job specifications, and automates React-controlled input fields via native prototype descriptor setters.
  • Side Panel UI (sidepanel.html/js): Provides a clean dashboard showing match percentage, skill gap breakdown, AI pitch generator, candidate profile editor, and application tracker.

3. Key Innovations

A. React Controlled Component Event Injection

Standard DOM property changes are ignored by React state listeners. The agent intercepts native HTMLInputElement descriptors and triggers bubbling input and change events to ensure full state synchronization.

B. Safety-First Human-in-the-Loop Protocol

The copilot advances through multi-page questionnaire steps but strictly halts before the final "Submit" button, giving the applicant full control and eliminating bot detection flags.

C. Dynamic Match & Gap Engine

Extracts required technologies from the job posting, compares them against the candidate's skills, and highlights missing keywords so the candidate can prepare for interviews.

4. Impact & Metrics

  • Application Speed: Reduced application completion time from ~5 minutes to under 30 seconds.
  • 100% Account Safety: Operates inside existing user sessions without external bot headers.
  • Built-in Tracking: Automatically records applied jobs with date, company, title, and CSV export.
